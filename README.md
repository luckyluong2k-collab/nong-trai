# Nông Trại Đức Lương

Game nông trại, câu cá pixel lấy cảm hứng từ dòng game mô phỏng đời sống, phát triển bằng **Godot 4**.

> Dự án sử dụng thế giới, nhân vật, mã nguồn và tài sản nguyên bản; không sao chép nội dung có bản quyền của Stardew Valley.

Bản prototype đầu tiên được phát triển trên nhánh riêng và đưa vào Pull Request để kiểm thử trước khi nhập vào `main`.
